# Executable Testbench — PCIe FLIT Foundation G1 (RTL v0.3)

## Read this first

This is an **executable, self-checking SystemVerilog verification suite for the
currently implemented prototype**, not a complete PCIe Gen1–Gen6 UVM verification
environment. The 76-entry matrix in `plan/` describes the **future** complete
controller effort and must not be interpreted as 76 passing tests.

For the existing DUT, this suite compares its TX/RX against FLITs generated by
an independent Python implementation of the PCIe 6.0 CRC/FEC. It validates
handshakes, packet-area placement, single-byte repair, corrupted-frame drop,
local CSRs, link guard, queue flushing, and standalone credit/sequence/LCRC
primitives. All relevant SV sources contain multi-line header comments.

## Dependencies

- Python 3 (standard library only), GNU Make, a shell, **Verilator >=5**.
- No commercial simulator required for the implemented G1 suites.
- Full future UVM signoff requires a compatible UVM simulator (not supplied).

Ubuntu:

```bash
sudo apt-get update
sudo apt-get install -y make python3 verilator
```

macOS:

```bash
brew install python verilator make
```

## Executable commands (from repository root)

```bash
make check                 # existing Python/structural checks; NO HDL
make tb-model              # independent Python golden-model tests; NO HDL
make lint                  # actual HDL syntax/elaboration; Verilator required
make tb-smoke              # actual top-module SV simulation (G1)
make tb-primitives         # actual standalone utility SV simulation (G1)
make tb-unit               # run both SV suites (G1)
make tb-regression         # both suites with seeds 1, 17, 42, 2026
make tb-smoke TB_SEED=123  # regenerate vectors and run chosen seed
```

`make tb-smoke` first generates `build/tb/vectors/*.hex`, then **compiles the
real RTL** plus `tb_pcie_gen6_g1.sv`, runs the simulator, and scans for the
success marker. Compilation failure, fatal test failure, missing simulator, or
watchdog timeout returns nonzero. `make tb-unit` runs both independent SV tops.

Outputs are written under `build/tb/`; test compile and simulation logs reside
under `build/tb/<test-top>/`. The top smoke suite also creates a VCD waveform.
Generated vectors, logs, object files and VCD are ignored by Git.

## What checks are implemented?

| Area | Independent oracle / observed behavior | Current G1 test |
|---|---|---|
| FLIT layout, CRC/FEC | Exact 256-byte Python-expected frame | `test_tx_frame` |
| TLP packer | 1, 4, 6, 17, 32, 41, 58, 59 DW; invalid 0/60/63 | `test_tx_frame`/`test_invalid_lengths` |
| TX handshake | No data loss / stable frame during backpressure | `test_tx_frame` |
| RX integrity | Clean FLIT and corrected byte at byte 235 | `test_rx_frame` |
| RX reject | Two-byte corruption in same ECC group is rejected | `test_rx_frame` |
| Link/mode guard | Gen1–Gen6, x1/x2/x4/x8/x16, invalid reports | `check_link_guard` |
| Engineering CSR | Signature, version, features, scratch, count and reset | `csr_read`/`csr_write` |
| Link-loss epoch | Pending TX/RX held frames must flush when L0 deasserts | `test_link_loss_flush` |
| Credit counter | Grant, consume, simultaneous, saturation | primitive suite |
| Sequence tracker | Normal, wrong sequence, clear, 1023→1 wrap | primitive suite |
| LCRC primitive | Known independent CRC32 vector, PCIe bit layout | primitive suite |
| Header probe | NOP detection and non-NOP Type | primitive suite |

## What does NOT yet exist (therefore NOT passed)

The RTL has no standard PCIe config/enumeration, memory request/completion
transaction layer, full DLL flow control, Ack/Nak, FLIT replay/sequence, legacy
non-FLIT transfer, LTSSM/ordered sets/equalization, physical PHY/PAM4, PIPE,
MSI-X/AER, DMA or Root Complex model. **No complete protocol UVM testbench**
or Gen1–Gen6 signoff is claimed. See `plan/TESTBENCH_MASTER_PLAN.md` and
`docs/DESIGN_GAPS.md` for required G2–G7 development.

## Known assumptions / limitations

- Clock/reset are a **single-domain functional prototype**, not a real PHY CDC.
- External `phy_l0`, mode, gen and width are supplied by the TB; not trained.
- Input is an already-formatted 1–59 DW FLIT-mode TLP, not generated from
  a host memory transaction. Random header bytes in vector tests are used to
  test packing/integrity only, **not TLP protocol validity**.
- `tx_dlp` is supplied by TB; it is not assembled from a real DLL handshake.
- Pending buffered frames are masked immediately when `flit_link_ready` drops
  and flushed on the next clock edge. This corrects one known v0.2 defect,
  but does not replace DLL link-loss state/transaction cancellation.
- Not tested on actual PCIe equipment. Passing G1 does **not** imply PCI-SIG
  compliance or Gen6 timing closure.

## Future extension path

Use the master plan in `plan/` as the roadmap. Add actual TL/DLL/PHY RTL and
only then add the corresponding UVM agents, scoreboards, coverage and legally
